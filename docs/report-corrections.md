# ข้อความแก้ไขสำหรับอัปเดตรายงาน PDF

ใช้หน้านี้แทน/เพิ่มเติมเนื้อหาเดิมในรายงาน PDF เพื่อให้ตรงกับ schema และระบบปัจจุบัน ก่อนส่งให้เติมชื่อสมาชิกคนที่ 2 และผลทดสอบจริงจากระบบ

## โครงสร้างฐานข้อมูลฉบับใช้งาน

ฐานข้อมูล MySQL ประกอบด้วย 8 ตาราง ได้แก่ `roles`, `users`, `categories`, `books`, `orders`, `order_items`, `payments` และ `download_links` โดย `users.role_id` อ้างถึง `roles.id`; `order_items.quantity` เก็บจำนวนเล่ม; และ `books.is_active` ระบุสถานะเปิดขาย บัญชีผู้ใช้เก็บ bcrypt password hash ส่วนการชำระเงินเป็นข้อมูลจำลองเท่านั้น

รายละเอียดชนิดข้อมูล, PK/FK, UNIQUE, CHECK และ DEFAULT อยู่ใน `docs/data-dictionary.md`; schema ที่รันได้อยู่ใน `database/schema.sql` และ migration สำหรับฐานข้อมูลเดิมอยู่ใน `database/migrate-current.sql`

ข้อมูลชื่อหนังสือ ราคา และ URL ใน `order_items` เป็น snapshot ณ เวลาซื้อเพื่อคงข้อมูลในใบสั่งซื้อเดิม ส่วน `orders.total_price` เป็นยอดรวม snapshot ที่ระบบคำนวณจากราคาและจำนวนสินค้าจากฐานข้อมูลระหว่าง checkout

## รายงาน SQL

ใช้ query ฉบับเต็มใน `database/reports.sql` แทน query เดิมใน PDF โดย query ยอดขายตามเวลาคำนวณ `SUM`, `COUNT`, `AVG` และกรองช่วงวัน; ยอดขายหนังสือและหมวดหมู่ใช้ `SUM(quantity)` และ `SUM(quantity * price)`; รายงานลูกค้าแสดงยอดซื้อสะสม และมี query แยกนับคำสั่งซื้อตามสถานะ

## ขอบเขตการดาวน์โหลด

ระบบสร้าง token เมื่อผู้ดูแลอนุมัติคำสั่งซื้อ และ route ดาวน์โหลดตรวจ token, เจ้าของคำสั่งซื้อ และสถานะ `approved` ก่อนส่งไฟล์ ไฟล์ที่อัปโหลดเก็บนอก public directory; URL ตัวอย่างภายนอกต้องเปลี่ยนเป็นไฟล์/URL ที่ได้รับอนุญาตก่อนสาธิต

## ผลทดสอบและข้อมูลจริง

ห้ามระบุว่าทดสอบผ่านจนกว่าจะทดสอบกับ MySQL/Aiven จริง ให้กรอกผลจริงลงใน `docs/test-cases.md` หลังรัน กรณีทดสอบต้องครอบคลุมจำนวนคำสั่งซื้ออย่างน้อย 30 รายการ และหลายสถานะ/ช่วงเวลา สคริปต์ `npm run seed:orders` เติมข้อมูลจำลองเท่าที่ขาดเพื่อให้จำนวนรวมถึง 30 โดยต้องมีบัญชีลูกค้าและหนังสือพร้อมขายอย่างน้อยหนึ่งรายการ

## สมาชิกและการใช้ AI

ใบงานกำหนดสมาชิก 2 คน ให้เพิ่มชื่อ/รหัสของสมาชิกทั้งสองและแบ่งส่วนที่แต่ละคนรับผิดชอบตามจริง บันทึก AI tool, วันที่, prompt โดยสรุป, ส่วนที่นำมาใช้ และวิธีตรวจสอบให้ตรงกับการใช้งานจริง ห้ามเติมรายละเอียดการใช้ AI หรือผลทดสอบที่ไม่ได้เกิดขึ้นจริง
