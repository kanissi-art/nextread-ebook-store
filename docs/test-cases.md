# ตารางทดสอบ NEXTREAD

หมายเหตุ: ผลจริงยังไม่ถูกบันทึก เพราะสภาพแวดล้อมนี้ไม่มี MySQL/MariaDB server ให้รันระบบและ seed ได้ ห้ามถือว่ากรณีด้านล่างผ่านจนกว่าจะรันจริง

| # | กรณี/ข้อมูลทดสอบ | ผลที่คาดหวัง | ผลจริง/สถานะ |
|---|---|---|---|
| 1 | สมัครด้วย user_id และอีเมลใหม่ | เพิ่มสมาชิกและบันทึกรหัสผ่านเป็น bcrypt hash | ยังไม่รัน: ไม่มี MySQL server |
| 2 | สมัครซ้ำด้วย user_id หรืออีเมลเดิม | ปฏิเสธการสมัคร ไม่สร้างสมาชิกซ้ำ | ยังไม่รัน: ไม่มี MySQL server |
| 3 | ค้นหาชื่อ/ผู้แต่งและเลือกหมวดหมู่ | แสดงเฉพาะหนังสือพร้อมขายที่ตรงเงื่อนไข | ยังไม่รัน: ไม่มี MySQL server |
| 4 | เพิ่มหนังสือในตะกร้า ปรับจำนวน และลบ | จำนวน/ยอดรวมเปลี่ยนตามข้อมูลในตะกร้า | ยังไม่รัน: ไม่มี MySQL server |
| 5 | Checkout ด้วยวิธีชำระจำลอง | สร้าง order, order_items พร้อม quantity และ payment ภายใน transaction | ยังไม่รัน: ไม่มี MySQL server |
| 6 | เปลี่ยนราคาหนังสือหลังเพิ่มเข้าตะกร้า | checkout ใช้ราคาปัจจุบันจากฐานข้อมูล ไม่เชื่อราคาใน session | ยังไม่รัน: ไม่มี MySQL server |
| 7 | เพิ่มหนังสือราคา 0 หรือติดลบ | CHECK constraint ปฏิเสธข้อมูล | ยังไม่รัน: ไม่มี MySQL server |
| 8 | Checkout หนังสือที่ถูกปิดขาย | ปฏิเสธ checkout และ rollback ไม่สร้าง order บางส่วน | ยังไม่รัน: ไม่มี MySQL server |
| 9 | เปิด /download/:token ของ order pending หรือของผู้ใช้อื่น | ตอบ 403 และไม่ส่งไฟล์ | ยังไม่รัน: ไม่มี MySQL server |
| 10 | Admin อนุมัติคำสั่งซื้อ pending | เปลี่ยนเป็น approved และสร้าง download token ต่อรายการ | ยังไม่รัน: ไม่มี MySQL server |
| 11 | Admin ยกเลิกคำสั่งซื้อ pending | เปลี่ยนเป็น cancelled และไม่เปิด download | ยังไม่รัน: ไม่มี MySQL server |
| 12 | รัน query รายงานจาก seed | แสดงยอดขาย, จำนวนเล่ม, หมวดหมู่, ลูกค้า และสถานะแยกได้ | ยังไม่รัน: ไม่มี MySQL server |
